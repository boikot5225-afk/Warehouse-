# L'Enfer WMS Bridge

Расширение Chrome/Edge/Яндекс Браузера связывает PWA L'Enfer с авторизованной вкладкой `wwh.samokat.ru`. Запросы к API выполняются внутри реального браузерного контекста WMS: с тем же IP, cookies и Servicepipe-сессией.

## Установка

1. Распаковать ZIP.
2. Открыть `chrome://extensions`.
3. Включить «Режим разработчика».
4. Нажать «Загрузить распакованное расширение» и выбрать эту папку.
5. Открыть PWA L'Enfer, нажать значок расширения → **Подключить открытую PWA**.
6. Открыть WMS кнопкой расширения, войти и дождаться полной загрузки.
7. Вернуться в PWA. Кнопки WMS используют тот же объект `window.LenferAndroidWms`, что Android-wrapper.

## Поддерживается

- поиск по УТ, ШК, названию, ячейке и ЕО;
- остатки и история изменений;
- исполнители и комбинированный поиск изменений;
- пересчёты, детали, подтверждение/отклонение;
- мониторинг отбора;
- создание ЕО;
- справочник ячеек, верхние ярусы и массовая проверка занятости;
- крупные минусы;
- маршруты отгрузки, упаковочные листы и PDF этикеток ячеек.

Системная установка APK и прямая TCP-печать на TSC относятся к Android и расширением не выполняются.
