# Lenfer Android WebView Wrapper — v39 universal WMS search

Рабочий сценарий:

1. Открыть APK.
2. Нажать **WMS** в нижней панели или кнопку авторизации внутри вкладки WMS.
3. Залогиниться во ВМС и дождаться полной загрузки.
4. Вернуться в **Приложение**.
5. Вкладка **WMS**.
6. Ввести УТ, ШК, название или ячейку.
7. Нажать **Найти**.

Поддержанные маршруты:

- `УТ-10547087` → `POST /products/search` с `PRODUCT_NOMENCLATURE_CODE` → `productId` → `POST /stocks/details`.
- `святой источник` или сканированный ШК → `POST /products/search` с `PRODUCT_NAME` → выбор товара при нескольких совпадениях → `POST /stocks/details`.
- `SH-11-62-2-1`, `HH-5-59-1-2`, `165B-1-1` → `GET /topology/cells/filters/by-address-search?cellAddressSearch=...` → `cellId` → `POST /stocks/details`.

В приложении показывается:

- для товара: ячейки, количество, зона, локация, срок, HU, статус;
- для ячейки: товары внутри ячейки, УТ, ШК, количество, срок, HU, статус.

Важно: если ВМС визуально открылась, но API отвечает 401/403, значит WebView не смог вытащить нужную авторизацию для API. Тогда нужен новый разбор заголовков ВМС.

## v55 — WMS Разбор

Добавлен режим `WMS → Разбор`. Он собирает в одну карточку:

- задания пересчёта;
- детализацию пересчётов по позициям, партиям, системе, факту и расхождениям.

Лучше всего работает по ячейке HH/SH. По УТ/названию связь с пересчётами строится по деталям пересчёта и названию товара, поэтому это вспомогательная аналитика, а не официальная связка ВМС.


## v56 — ИИ-разбор через Yandex Cloud + DeepSeek

В `WMS → Разбор` добавлен компактный блок **ИИ-разбор**. После сбора фактов можно выбрать одно действие:

- Что произошло?
- Что проверить?
- Черновик проблемы

Приложение передаёт в Yandex Cloud только уже собранные данные разбора: остатки, историю изменений, пересчёты и детализацию. Токены и cookies WMS в запрос не попадают. Firebase ID token используется только для доступа к функции.


## v58 — WMS пересчёты в отчёте (прототип)

В разделе «Отчёт» добавлен блок **WMS · пересчёты в отчёт**. По нажатию «Подтянуть» Android-обёртка загружает завершённые задания пересчёта за выбранную дату и предлагает записать их в четыре стандартные строки отчёта: по заданиям/плановый × Холод/Сухой.

Прототип использует прозрачное правило классификации: **плановый** = `FULL + CREATED_ON_PDT`; **по заданиям** = остальные завершённые задания. В результатах это правило показано прямо на экране, чтобы его можно было быстро уточнить по реальной практике WMS.

В этот же блок добавлена кнопка **ИИ-сводка**: DeepSeek получает только агрегированную сводку без ФИО и формирует короткий рабочий текст по объёму пересчётов и исключениям.


## v58 — фикс авторизации ИИ
Yandex Cloud использует стандартный заголовок Authorization для IAM-авторизации. Поэтому Firebase-токен передаётся в `X-Firebase-Token`; это предотвращает 403 до запуска функции.
