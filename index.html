ExecutorId / точный фильтр
Излишки
Загружает завершённые пересчёты исполнителя, находит позиции с расхождениями. Холод и Сухой переносятся в отчёт раздельно.
Поиск изменений по исполнителю и/или дате
Отдельный поиск истории изменений остатков за период. Фамилия исполнителя не обязательна — можно искать только по датам, только по фамилии, или вместе. Для поиска по товару, УТ, ШК, ячейке или ЕО используй поле выше.
Разбор WMS
Собирает в одну карточку остатки, историю изменений, пересчёты и позиции внутри пересчётов. Лучше всего работает по ячейке: HH/SH.
Резерв / отбор в ячейке
Введи ячейку хранения. Приложение запросит её остатки в WMS и покажет только ЕО со статусом резерва под заказ или отбора. Заказы здесь не выводятся: вопрос один — есть в этой ячейке отбор или нет.
Верхние ярусы хранения
Сначала грузится полный справочник /topology/cells без скрытых WMS-фильтров; затем приложение оставляет HH/SH и ярусы 2+. Адрес: SH-4-54-3-2 → ряд 4 · секция 54 · место 3 · ярус 2.
Первый ярус хранения
Справочник берётся из полного /topology/cells; здесь остаются только ячейки, у которых последняя цифра адреса — 1: SH-4-54-3-1. В поле «Ряд» можно указать несколько рядов через запятую: 4, 7, 12.
Ячейки склада · ШК · остатки
Загрузи весь справочник ячеек склада и фильтруй по зоне (холод / сухой / ворота). Для каждой ячейки — штрихкод и переход к её остаткам. Жми ★ на нужных ячейках — попадут в «Избранное»; поиск и фильтр зоны работают и внутри него.
Маршруты отгрузки
Введи любые слова из адреса магазина — порядок неважен, поиск гибкий.
Крупные недостачи и списания
Только два источника: недостачи по пересчётам и списания из хранения. Отгрузки и перемещения сюда не попадают.
